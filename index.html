토끼 단어 상점

단어를 맞히고 코인을 모아 토끼를 꾸며 보세요
게임 방법
  1. 단어 입력 탭에서 apple - 사과 형식으로 단어를 넣어요.
  2. 퀴즈는 영어→한글, 한글→영어가 랜덤이고 4지선다나 주관식으로 나와요.
  3. 정답이면 +5코인, 오답이면 -10코인이에요. 코인은 0 밑으로 내려가지 않아요.
  4. 맞히면 토끼가 웃고, 틀리면 울거나 화내요.
  5. 진행은 자동 저장돼요. 저장 버튼으로 직접 저장할 수도 있고, 다음에는 이어하기로 계속해요.
  6. 상점에서 코인으로 아이템을 살 수 있어요. 돈이 모자라면 주인 오리가 화내요.
토끼 단어 상점 0
한 줄에 하나씩 apple - 사과 형식으로 입력하세요. 뜻이 여러 개면 쉼표로 구분해요 (예: run - 달리다, 뛰다).
